# SEO-продвижение сайта BelCouch

SEO-продвижение сайта – это комплекс действий по внутренней и внешней оптимизации, направленных на повышение позиций сайта в поисковой выдаче.

SEO-продвижение сайта включало внутреннюю и внешнюю оптимизацию. Данные действия направлены на улучшение индексации страниц сайта, рост органического трафика и повышение доверия к бренду.

Для платформы краткосрочной аренды жилья «BelCouch» было составлено семантическое ядро. Семантическое ядро – это набор ключевых слов, которые описывают сайт и то, что на нем размещается. Правильное семантическое ядро помогает структурировать сайт. С помощью сервиса WordStat были подобраны ключевые слова, релевантные тематике краткосрочной аренды жилья.

## Подбор ключевых слов

Основные ключевые слова для платформы:
- Аренда квартиры посуточно
- Снять жилье в Минске
- Краткосрочная аренда жилья
- Жилье на сутки
- Аренда квартиры в Беларуси
- Посуточная аренда квартир
- Жилье для гостей
- Сдача жилья в аренду
- Квартира на день
- Жилье с удобствами

Дополнительные ключевые слова по регионам:
- Аренда жилья в Минске
- Квартиры в Бресте посуточно
- Жилье в Гродно на сутки
- Аренда в Витебске
- Жилье в Гомеле
- Квартиры в Могилеве

Для каждой из страниц веб-сайта были заданы уникальные мета-теги title, description и keywords. Тег title включает ключевые слова, соответствующие содержанию страницы, и сформирован в виде короткой, читаемой, осмысленной и информативной фразы. Мета-тег description содержит сжатое описание страницы, которое может отображаться в сниппете поисковой выдачи. Тег keywords указывает ключевые слова, отражающие тематику всей страницы, на которой располагается контент.

### Примеры мета-тегов для основных страниц

**Главная страница:**
- Title: BelCouch – аренда жилья посуточно в Беларуси. Снимайте квартиры и дома на сутки
- Description: Платформа BelCouch предлагает широкий выбор жилья для краткосрочной аренды в Беларуси. Удобный поиск, проверенные хозяева, безопасное бронирование.
- Keywords: аренда жилья, посуточно, краткосрочная аренда, снять квартиру, жилье в Беларуси, BelCouch

**Страница каталога объявлений:**
- Title: Каталог жилья – аренда квартир и домов посуточно в Беларуси | BelCouch
- Description: Ищете жилье на сутки? Просмотрите каталог объявлений на BelCouch. Квартиры, дома, комнаты в разных городах Беларуси с фото и отзывами.
- Keywords: каталог жилья, объявления аренды, снять жилье, квартиры посуточно, аренда домов

**Страница профиля пользователя:**
- Title: Профиль пользователя – BelCouch
- Description: Просмотрите профиль пользователя на BelCouch. Отзывы, рейтинг, информация о хозяине и его объявлениях жилья.
- Keywords: профиль пользователя, отзывы о хозяине, рейтинг хозяина, аренда жилья

Также на сайте была проведена проверка правильности использования тегов, их структуры, а также наличия и корректности заполнения атрибутов title и alt у изображений. Эти атрибуты важны для оптимизации графического контента. Атрибут alt представляет собой текстовую альтернативу изображению и отображается в случае, если изображение не загружается. Атрибут title показывает всплывающую подсказку при наведении курсора и выполняет функцию заголовка изображения.

### Листинг 5.1 – Атрибуты alt и title

```html
<img src="./assets/img/listings/123/main.jpg" alt="Квартира в центре Минска с двумя спальнями" title="Современная квартира в Минске">
```

На сайте была организована внутренняя перелинковка, реализованы перекрестные ссылки между карточками объявлений, профилями пользователей и страницами категорий. Это повышает глубину просмотра, способствует лучшему ранжированию и упрощает навигацию для пользователя. Также внутренняя перелинковка помогает поисковым системам лучше понимать структуру сайта. Связи реализованы через:
- Ссылки на профиль владельца из карточки объявления
- Ссылки на объявления из профиля пользователя
- Связанные объявления в разделе «Похожие варианты»
- Хлебные крошки для навигации

Для управления процессом индексации сайта был создан и настроен файл robots.txt. С его помощью можно задать правила, ограничивающие доступ поисковых роботов к отдельным разделам или страницам.

### Листинг 5.2 – Файл robots.txt

```
User-agent: *
Allow: /

Disallow: /api/
Disallow: /app/
Disallow: /includes/
Disallow: /assets/js/
Disallow: /assets/css/
Disallow: /TelegramBot/
Disallow: /bootstrap.php

Sitemap: https://belcouch.by/sitemap.xml
```

Также для поисковых систем была создана карта сайта в формате sitemap.xml. Этот файл помогает поисковым роботам определить расположение всех страниц сайта, дату их последнего обновления, частоту изменений и относительную важность каждой страницы. Такая информация способствует более эффективной и логичной индексации сайта. В sitemap.xml были указаны все доступные страницы ресурса, что облегчает поисковику понимание его структуры. При этом важно, чтобы sitemap.xml и robots.txt не противоречили друг другу: все страницы, закрытые от индексации в robots.txt, также не должны присутствовать в карте сайта.

### Листинг 5.3 – Структура sitemap.xml

Карта сайта включает:
- Главную страницу
- Страницу каталога объявлений
- Страницы всех активных объявлений
- Страницы профилей верифицированных пользователей
- Страницу поддержки
- Страницу о проекте

Для пользователей, перешедших по несуществующим ссылкам, разработана отдельная страница 404, стилизованная под бренд BelCouch. Она содержит навигацию на основные разделы сайта (каталог, о проекте, поддержка), чтобы минимизировать риск ухода с ресурса. Страница также предлагает пользователю воспользоваться поиском по объявлениям или вернуться на главную страницу.

Оптимизация скорости загрузки веб-сайта проводилась за счет установки порядка загрузки файлов стилей и скриптов, а также за счет настройки механизма кеширования данных. Все скрипты были подключены в конце страницы, что позволяет загружаться им только после полной загрузки основной информации на сайте. Механизм кеширования данных был настроен в файле .htaccess для статических ресурсов (изображения, CSS, JavaScript).

### Листинг 5.4 – Настройка кеширования в .htaccess

```
<IfModule mod_expires.c>
    ExpiresActive On
    ExpiresByType image/jpeg "access plus 1 year"
    ExpiresByType image/png "access plus 1 year"
    ExpiresByType image/gif "access plus 1 year"
    ExpiresByType text/css "access plus 1 month"
    ExpiresByType application/javascript "access plus 1 month"
</IfModule>
```

Дополнительные меры по оптимизации:
- Сжатие изображений перед загрузкой на сервер
- Использование lazy loading для изображений в каталоге
- Минификация CSS и JavaScript файлов
- Оптимизация SQL-запросов для быстрой загрузки данных
- Использование CDN для статических ресурсов (в перспективе)

Таким образом, комплексная SEO-оптимизация платформы «BelCouch» заложила основу для успешного продвижения ресурса в поисковых системах и повышения его узнаваемости среди целевой аудитории.
