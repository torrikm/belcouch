# Визуальные эффекты и дизайнерские элементы

Использование на сайте разнообразных визуальных эффектов и дизайнерских элементов способствует усилению эстетической составляющей сайта и повышению вовлечения пользователей, а также улучшает их взаимодействие с интерфейсом.

Основным направлением визуального оформления стал акцент на современность, удобство и интуитивность интерфейса, соответствующие платформе краткосрочной аренды жилья.

На сайте реализованы эффекты анимации при наведении мыши на кнопки с классом .btn. Эффект работает при помощи псевдокласса :hover, которому задается новый цвет фона. Плавное изменение цвета фона создает эффект интерактивности, реализованный с помощью CSS-перехода transition. Это помогает визуально выделить кнопку и подталкивает пользователя к действию. Реализация стилей оформления кнопки при наведении приведена в листинге 4.5.

```css
.btn {
  background-color: var(--dark-blue-button);
  color: var(--white-button);
  transition: background-color 0.3s ease;
}

.btn:hover {
  background-color: var(--primary-hover);
}
```

Листинг 4.5 – Стили кнопки при наведении

Для навигационных элементов шапки сайта реализован эффект плавного изменения прозрачности при наведении. Это достигается с использованием свойства opacity и CSS-перехода transition. При наведении на элементы навигации их прозрачность уменьшается до 0.8, что создает эффект интерактивности. В листинге 4.6 представлены стили оформления навигационных элементов при наведении.

```css
.nav-item {
  transition:
    color 0.3s ease,
    opacity 0.3s ease;
}

.nav-item:hover {
  opacity: 0.8;
}
```

Листинг 4.6 – Стили навигационных элементов при наведении

Поля ввода формы также имеют визуальный эффект при фокусе. При получении фокуса поле ввода меняет цвет границы на основной цвет сайта (темно-синий), что помогает пользователю понять, какое поле активно в данный момент. Эффект реализован через псевдокласс :focus с плавным переходом цвета границы. В листинге 4.7 представлены стили оформления полей ввода при фокусе.

```css
input {
  outline: none;
  transition: border-color 0.3s ease;
}

input:focus {
  border-color: var(--primary-color);
}
```

Листинг 4.7 – Стили полей ввода при фокусе

Карточки регионов на главной странице анимированы при наведении. При наведении на карточку она слегка поднимается вверх и увеличивается тень, что создает эффект глубины и интерактивности. Эффект реализован через свойства transform и box-shadow с плавными переходами. В листинге 4.8 представлены стили оформления карточек регионов при наведении.

```css
.region-card {
  transition:
    transform 0.3s ease,
    box-shadow 0.3s ease;
  box-shadow: 0 4px 15px rgba(0, 0, 0, 0.1);
}

.region-card:hover {
  transform: translateY(-2px);
  box-shadow: 0 8px 20px rgba(0, 0, 0, 0.15);
}
```

Листинг 4.8 – Стили карточек регионов при наведении

Для мобильной навигации реализована анимация открытия и закрытия меню. Меню плавно появляется с изменением высоты, прозрачности и отступов. Эффект реализован через CSS-переходы нескольких свойств одновременно: max-height, opacity, padding и visibility. Это создает плавный и естественный эффект раскрытия меню. В листинге 4.9 представлены стили мобильной навигации.

```css
.main-navigation {
  max-height: 0;
  overflow: hidden;
  opacity: 0;
  visibility: hidden;
  transition: max-height 0.3s ease, opacity 0.3s ease, padding 0.3s ease, visibility 0.3s ease;
}

.main-navigation.active {
  max-height: 500px;
  opacity: 1;
  visibility: visible;
  padding: 15px;
}
```

Листинг 4.9 – Стили мобильной навигации

Кнопка прокрутки вверх имеет анимацию появления. Кнопка изначально скрыта и смещена вниз, при прокрутке страницы она плавно появляется и занимает нужную позицию. Эффект реализован через свойства opacity и transform с CSS-переходами. В листинге 4.10 представлены стили кнопки прокрутки вверх.

```css
.global-scroll-top {
  opacity: 0;
  transform: translateY(10px);
  pointer-events: none;
  transition: opacity 0.2s ease, transform 0.2s ease, background-color 0.2s ease;
}

.global-scroll-top.is-visible {
  opacity: 1;
  transform: translateY(0);
  pointer-events: auto;
}

.global-scroll-top:hover {
  background: #2745aa;
}
```

Листинг 4.10 – Стили кнопки прокрутки вверх

Слайдер на главной странице имеет плавную анимацию переключения слайдов. Переход между слайдами реализован через свойство transform с CSS-переходом, что создает эффект плавного перемещения. Точки пагинации также имеют анимацию изменения прозрачности при переключении активного состояния. В листинге 4.11 представлены стили слайдера.

```css
.slider {
  display: flex;
  transition: transform 0.5s ease;
}

.slider-dot {
  background-color: #ffffff;
  opacity: 0.5;
  cursor: pointer;
  transition: opacity 0.3s;
}

.slider-dot.active {
  opacity: 1;
}
```

Листинг 4.11 – Стили слайдера

Результаты поиска имеют эффект подсветки при наведении. При наведении на элемент результата поиска его фон меняется на светло-голубой цвет, что помогает пользователю визуально отследить выбранный элемент. Эффект реализован через псевдокласс :hover с плавным переходом цвета фона. В листинге 4.12 представлены стили результатов поиска при наведении.

```css
.search-result-item {
  transition: background-color 0.2s ease;
  border-bottom: 1px solid #f1f1f1;
}

.search-result-item:hover {
  background-color: #f1f7ff;
}
```

Визуальные эффекты и элементы дизайна сайта реализованы таким образом, чтобы сочетать современность, удобство и интуитивность, соответствующие платформе краткосрочной аренды жилья. Использование плавной анимации помогает сформировать доверие пользователей к платформе и улучшает общий пользовательский опыт.
